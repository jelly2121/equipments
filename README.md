# SAD Equipment Borrowing and Return Monitoring System

## Technologies
- HTML
- CSS
- JavaScript
- Supabase PostgreSQL
- Supabase Authentication
- GitHub Pages

## Setup

1. Create a Supabase project.
2. Open Supabase SQL Editor.
3. Run `database.sql`.
4. Create a user under Authentication > Users.
5. Open `js/supabase.js`.
6. Replace `YOUR_SUPABASE_PROJECT_URL` with your Supabase Project URL.
7. Replace `YOUR_SUPABASE_ANON_KEY` with your public anon/publishable key.
8. Test `login.html`.
9. Upload the project to GitHub.
10. Enable GitHub Pages.
